# Skywork - Full-Stack HR & Workspace Management Platform

This repository contains the complete full-stack codebase for the Skywork platform:

## Project Structure

```
Product Skywork/
├── SKYWORK/      # Frontend application (React 19 + Vite + TailwindCSS)
├── Server/       # Backend API (Node.js + Express + MongoDB)
└── README.md
```

## Getting Started

### 1. Backend Setup
```bash
cd Server
npm install
npm run dev
```

### 2. Frontend Setup
```bash
cd SKYWORK
npm install
npm run dev
```
